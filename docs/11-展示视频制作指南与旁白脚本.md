# 11｜展示视频分镜设计与旁白脚本（90秒 / 3分钟版）

> 本指南专为制作「晶流 LabFlow」展示视频而编写。通过将系统运行时画面、操作轨迹与旁白口播完美同步，你或大模型配音工具可以轻松录制出一份极具说服力的演示视频。

---

## 一、视频技术规范建议

*   **视频时长**：推荐 **90秒**（适合快速筛选）或 **3分钟**（适合详细评审）。
*   **分辨率与比例**：1080P (1920×1080)，16:9 横屏。
*   **录屏环境**：
    *   启动本地服务：`npm start`
    *   在浏览器打开：`http://localhost:4173`
    *   推荐分辨率：1440×900 或 1920×1080，控制台无报错。
*   **配音建议**：使用清晰、沉稳的男声或女声。如需 AI 自动配音，可将以下旁白文字直接复制到剪映、Edge TTS 或 ElevenLabs 中，使用“科技感/商务配音”音色生成。
*   **背景音乐**：选择轻快、柔和、科技感（Ambient / Corporate Tech）的背景音乐，音量控制在 10% 左右，避免掩盖人声。

## 四、录屏与剪辑实操步骤

1.  **启动本地演示环境**：
    在 PowerShell 中进入项目目录，执行：
    ```powershell
    npm start
    ```
    用 Chrome 或 Edge 浏览器访问 `http://localhost:4173`。按 `F11` 进入全屏模式，或者调整浏览器大小为 `1440×900` 左右（这会让布局看起来紧凑而专业）。

2.  **屏幕录制**：
    *   **Windows 自带录屏**：按下快捷键 `Win + Alt + R` 开始/停止录屏（生成的文件存放在“视频/捕获”文件夹下）。
    *   **专业工具**：推荐使用 OBS Studio（免费开源），设置录制格式为 MP4，码率 6000 Kbps，帧率 60 FPS，能够捕捉到非常平滑的鼠标移动和弹窗特效。
    *   **录制技巧**：鼠标移动要平缓，点击后停留 1~2 秒让观众看清页面变化，不要有无意义的鼠标晃动。

3.  **音频生成与合成**：
    *   你可以自己对照脚本朗读，也可以直接将上述旁白文字复制到剪映、飞书妙记或 Edge TTS 转换工具中。
    *   导入剪辑软件（如剪映、PR），将录屏视频按照时间轴切片，并与音频对齐。
    *   在视频关键卡片（如“24h SLA”、“证据时间戳”、“失败案例 A-09”）上，使用黄色或青色半透明方框进行局部高亮或放大放大特效，增加视觉冲击力。
    *   最后导出为 `mp4` 格式，文件大小控制在 50MB-100MB 以内以便于上传。
