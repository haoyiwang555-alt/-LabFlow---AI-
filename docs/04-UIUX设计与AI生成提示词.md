# 04｜UI/UX 设计说明与 Demo 生成提示词

## 1. 设计概念

**概念：Living Research Memory / 会生长的研发记忆。**  
实验不是一张表格，而是由会议、参数、证据、风险和人共同组成的生命网络。视觉上避免常见“蓝紫渐变 AI 大屏”，采用深墨色、实验荧光绿、薄荷绿、珊瑚红和纸张灰，让界面同时具有科研严谨感与 AI 活力。

### 视觉关键词

- scientific editorial：科研编辑感、清晰编号、克制排版。
- bio-digital：生物与数字连接，轨道、节点、证据链。
- calm confidence：信息密度高但不焦虑。
- traceable：每个结论能找到来源，每个操作有状态。

### 设计 Token

| Token | 值 | 用途 |
|---|---|---|
| Ink | `#10202A` | 侧栏、主标题、主按钮 |

| Mint Deep | `#2A9E76` | 已完成、可复用 |
| Aqua | `#7ADBD3` | 进行中、数据流 |
| Coral | `#F17969` | 风险、需要人审 |
| Violet | `#9D92FF` | 知识图谱、语义关联 |

字体：优先 Inter / SF Pro Display / PingFang SC。标题使用紧字距，正文使用 1.6-1.8 行高。圆角控制在 8-20px，避免所有元素都变成胶囊。阴影只用于英雄区、弹窗和重要浮层。

## 3. 核心页面规格

### A. 研发总览

- 顶部一句话：让每一次讨论，成为下一次发现。
- 英雄区左侧讲 24h 知识闭环，右侧使用实验室图片、椭圆轨道和三个节点表现“参数—证据—复用”。
- 四个指标卡：24h SLA、平均复用耗时、进行中实验、待处理风险。
- 实验研发闭环：5 步状态流，绿色完成、青色进行中、珊瑚色关注。
- 会议智能解析列表：明确“开始解析”和“查看结论”两种状态。
- 右栏：知识复用雷达、实时活动、设计原则引用。

### B. 会议解析弹窗

1. 选择会议；2. 明确说明演示/生产适配器；3. 解析过程中展示阶段性状态；4. 结果按“方案决策/风险提示/知识关联”排序；5. 每条结论展示证据时间戳；6. 行动项展示负责人、截止与优先级；7. 末尾明确“写入知识湖并同步多维表”。

### C. 实验流转

卡片不能只显示进度条，还要包含实验编号、名称、团队、负责人、阶段、风险、更新时间和 AI 洞察。图片仅作为语境入口，信息本体保持文本清晰。

### D. 知识湖

左侧用关系网络表达当前实验与历史方案、失败案例、SOP 和会议证据的关联；右侧按相关度展示知识条目。图谱不是装饰，节点类型和颜色要有图例。

### E. AI 助理

以三个专用 Agent 取代通用聊天框：会议解析器、实验相似检索、风险守门员。底部运行日志显示 Agent 名称、运行结果、置信度和风险动作，突出后端可观测性。

## 4. 关键 UX 原则

1. **先给结论，再给证据。** 结论可扫读，证据可展开回看。
2. **AI 永远显示状态。** 待解析、运行中、需确认、已批准、失败重试必须可区分。
3. **风险不只用颜色。** 同时用文字标签和优先级，满足可访问性。
4. **保留人类控制权。** 高风险结论写入前必须人工确认。
5. **降低认知切换。** 会议、任务、实验、知识都围绕同一实验编号。
6. **移动端保留主链路。** 小屏优先会议解析与知识检索，图谱可简化。
7. **不使用原生表情包。** 图标使用 CSS 线性图形或统一 SVG，不用系统 Emoji。

## 5. 可用性测试任务

- T1：用户能否在 30 秒内找到 B-17 最新决策和证据时间戳。
- T2：用户能否识别 A-09 当前最大风险和负责人。
- T3：用户能否把会议 mt-2407 解析为行动项并写入闭环。
- T4：用户能否搜索“湿度”并找到失败案例。
- T5：用户能否区分“演示适配器”与“真实飞书连接器”。

成功标准：任务完成率 ≥ 90%，平均 SEQ 易用度 ≥ 5.5/7，关键误解为 0。

> 用于妙搭、Figma AI、Claude Artifacts、Lovable 或其他 UI 生成工具。建议分页面生成，不要一次塞入所有页面。

```text

核心任务：把飞书会议里的实验参数、方案争议、风险、决策、证据时间戳和行动项转化为可复用的研发知识资产，并连接实验状态、文档、知识库和多维表格。产品主张：“让每一次讨论，成为下一次发现。”核心指标：“24h 知识 SLA”。

视觉风格：scientific editorial + bio-digital，严谨、克制、先进，不要蓝紫霓虹渐变，不要游戏化，不要玻璃拟态堆叠。主色深墨绿黑 #10202A，背景纸张灰 #F5F7F2，关键行动荧光青柠 #CBF65D，成功薄荷 #C9F4D9，进行中水蓝 #7ADBD3，风险珊瑚红 #F17969，知识关联紫 #9D92FF。使用 Inter/PingFang SC，标题紧字距，正文清晰。图标必须使用统一线性 SVG，不使用原生 Emoji。

整体布局：左侧 252px 深色固定侧栏，包含品牌标记、工作区切换、研发总览、实验流转、知识湖、AI 助理、连接器、偏好设置、AI 额度和用户卡；顶部 72px 工具栏，包含面包屑、全局搜索、通知和帮助；主内容最大宽 1440px。

首页：顶部标题“让每一次讨论，成为下一次发现。”英雄区左侧展示“从会议到知识资产，不再让好结论失联”，右侧放真实科研实验室摄影，叠加两条椭圆数据轨道、实验参数/决策证据/知识复用三个节点，以及“KNOWLEDGE SLA 24h”浮动卡片。下方四个指标卡：24h 知识 SLA 87%、平均复用耗时 6.4 小时、进行中实验 12 项、待处理风险 3 项。

请保证：桌面 1440×1024，信息层级明确，WCAG AA 对比度，按钮状态完整，使用真实中文业务文案，图片占比克制，卡片边框细腻，只有关键浮层使用阴影。输出一张完整高保真仪表盘图和一张会议 AI 解析弹窗图。
```

## 7. 分页面提示词

### 会议解析弹窗

```text
为“晶流 LabFlow”设计 620px 宽的会议 AI 解析弹窗。顶部标题“AI 会议解析器”，先选择 B-17 参数评审会议；解析完成后展示三条结构化结果：方案决策、风险提示、知识关联。每条结果必须包含结论、置信度、原文时间戳。下方展示两个行动项及负责人和截止时间，底部主按钮“写入知识湖并同步多维表”。风格沿用深墨色、青柠、薄荷、珊瑚红；不用聊天气泡，不用 Emoji。
```

### 知识湖

