# 08｜视觉素材与合规清单

## 使用原则

- 项目包含 12 张从 Unsplash 下载的高质量科研/协作图片，均已本地化到 `public/assets/`，现场演示不依赖外网。
- 不使用原生表情包作为功能图标；界面图标采用 CSS 线性图形、字符标记或后续可替换的统一 SVG。
- 图片用于竞赛原型和演示背景，不暗示图片中的人物或机构为晶泰科技员工/设施。
- 提交或公开部署前再次核对 Unsplash 最新 License 与人物/商标/场地授权要求；若用于商业广告或对外宣传，需进一步进行权利审查。

## 项目数据合规

- `data/seed.json` 中所有实验编号、人员、参数与结论均为竞赛演示构造数据，不代表晶泰科技真实业务数据。
- 页面中的 87%、42 小时、1.5 天等数字是演示/目标数据，不是企业实际成绩。
- 未经授权不上传企业会议、文档、实验参数、药物代号或人员信息到第三方模型。
- 后续拿到企业样本时优先使用企业租户内模型与数据处理能力，并完成脱敏、权限和审计设计。

- [ ] 报名附件中的个人信息仅通过官方表单提交，不公开到代码仓库。

- [ ] 使用赛事/企业 Logo 前确认赛事规则允许；当前产品界面不直接嵌入晶泰或飞书官方 Logo 文件。
